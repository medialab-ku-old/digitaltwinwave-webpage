# (주)디지털트윈웨이브 인재 채용

## 회사 소개 및 비전

디지털트윈웨이브는 현실 공간을 이해하고, 예측하며, 실행 가능한 지능으로 확장하는 ‘공간 지능(Spatial Intelligence)’ 기술 기업으로, 디지털 트윈, AR, Physical AI를 결합하여 제조·건설·물류·로보틱스 현장의 실제 문제를 해결하는 실용적 기술을 연구개발하고 있음.

## 모집 개요

- 디지털 트윈, AR, Physical AI 기반 차세대 공간 지능 기술 개발 인재 모집
- 학사(산업체 2년 이상 경력) 학위 혹은 석사/박사 학위 소지자

## 모집 분야

- PM (Project Manager) 1인
- SW 개발자 - 5개 세부 분야 각각 복수의 개발자 모집 (하단 참조)
    - 3차원 재구성
    - 디지털 트윈 시뮬레이션
    - AR 기반 시공 및 형상유지 점검
    - 대형 3차원 모델 실시간 렌더링
    - Physical AI

## 근무 환경
- 근무지: 고려대학교 안암캠퍼스
- 근무 형태: 유연 근무제 (협의)
- 급여: 
    - 대외 경쟁력 있는 급여 및 보상
    - 고성능 GPU서버 등 연구·개발 인프라 제공 
    - 연구·기술 성과의 논문 발표 지원
- 근무 개시일: 협의 (1월 근무 개시 가능)

## 1. PM (Project Manager)

**담당 업무**
- 중장기 사업 전략 수립 및 로드맵 관리
- 일정, 산출물, 성과지표 관리
- 제안서, 보고서, 기술 문서 작성
- 대외 협력 및 프로젝트 커뮤니케이션 총괄

**우대사항**
- 기술 기반 R&D 프로젝트 PM 경험
- 디지털 트윈, AI, XR, 로보틱스 분야 이해

## 2. SW 개발자
### 2-1. 3차원 재구성

**담당 업무**
- Large-scale multi-view 데이터셋 제작
- Segmentation 네트워크 개발
- 2D instance to 3D CAD model

**우대사항**
- 3D Gaussian Splatting, NeRF 구현 경험
- Visual SLAM, SfM 파이프라인 개발 경험
- 대규모 영상 데이터셋 제작·관리 경험
- CUDA 프로그래밍

### 2-2. 디지털트윈 시뮬레이션

**담당 업무**
- 2D to 3D 변환 (실내 2차원 도면으로부터 3차원 모델 구축)
- 유체 혹은 로봇 시뮬레이션 
- 대규모 디지털트윈 환경 시뮬레이터 설계 및 구축
- Unity, Unreal Engine 기반 시뮬레이션 파이프라인 개발

**우대사항**
- Unity, Unreal Engine 활용 경험
- 물리 시뮬레이션(Issac Sim, MuJoCo 등) 개발 경험

### 2-3. AR 기반 시공 및 형상유지 점검
**담당 업무**
- 모바일 AR 기반 실시간 3차원 정합 파이프라인 설계
- 3차원 구조와 BIM 데이터 간 정합·정확도 평가
- 시공 오차, 형상 변형 자동 검출 및 시각화 기능 개발

**우대사항**
- ARKit, ARCore 등 모바일 AR 개발 경험
- IFC, RVT 등 BIM 데이터 처리 경험
- Visual SLAM, SfM 파이프라인 개발 경험

### 2-4. 대형 3차원 모델 실시간 렌더링
**담당 업무**
- Ray Tracing, Path Tracing 기반 실시간 렌더링 기술 개발
- 대규모 장면 GPU 가속 구조 설계 및 최적화
- Vulkan RT, WebGPU 등 그래픽 API 활용

**우대사항**
- GPU 프로그래밍 성능 최적화 경험
- 실시간 렌더링 엔진 개발 경험
- Vulkan, DirectX 12, OptiX, WebGPU 활용 경험

### 2-5. Physical AI
**담당 업무**
- Embodied Agent 시스템 연구·개발
- 시뮬레이터(Isaac Sim, Unity) 기반 AI 파이프라인 설계
- World Model, 행동 계획, 상호작용 모델 설계 및 실험
- 디지털 트윈 기반 Sim-to-Real 연구·개발

**우대사항**
- World Model, Embodied AI, 강화학습 연구 경험
- 로보틱스 또는 Physical Simulation 프로젝트 경험
